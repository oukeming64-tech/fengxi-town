# 枫溪镇

给高金-上国会凯瑞商学院 22 期同学的一份毕业礼物。

[在线打开枫溪镇](https://oukeming64-tech.github.io/fengxi-town/)

![枫溪镇地图预览](gift-assets/map.png)

这里是一座可以打开的小镇。进去以后，可以看地图、看居民今天在哪里、看公告板、看今日小事，也可以等一天结束后读一份镇上小报。

## 怎么进入

最简单的方式是打开上面的在线链接，然后点击“打开枫溪镇”。

首页的[居民的第一天](https://oukeming64-tech.github.io/fengxi-town/#day-1)可以直接在手机上读。展开行程或相遇记录，就能看到这一次 30 位居民实际去了哪里、谁找了谁。三段对白按当天事件和 DeepSeek 试稿编辑。

如果想在自己电脑上运行，下载这个仓库后直接打开 `index.html` 也可以；本地入口会进入 `town/index.html`。

## 居民 AI

开启“居民 AI”后，TypeSafe Jev 为每位居民挑清晨、午后和夜里的活动，再从同一时段能在同一处碰见的人中挑对象，决定交谈、帮忙、送礼、道谢、等候、避开或各忙各的。本地引擎根据当时的体力、活动条件和两人实际到场的情况结算。DeepSeek 从当天已经发生的相遇中写最多三段对白，可以在地图和“镇上对话”里回看。连续推进多天时，每天都会重新做决定。

居民打算交谈时，Jev 也会选他为什么想找这个人。他可能想打听消息、试探对方肯不肯帮忙，也可能只是想逗人一笑。DeepSeek 根据这个来意、各自看见的事和两人以前碰面的记录写两到三个话轮。

### 在在线网页版开启

打开小镇，把“居民 AI”设为“开启”，填入自己的 OpenRouter key 并保存，再点“推进”。网页直接向 OpenRouter 请求 Jev 和 DeepSeek，使用持有人的模型额度。Key 仅在当前标签页内有效，刷新或点击“清除页面 key”即可清除。不开启时也可以用本地规则游玩。

### 在本机开启

1. 在仓库目录运行 `node server.js`，然后打开本地 `index.html`，进入小镇。
2. 点“配置”，选择对白平台 `OpenRouter`，对白模型使用默认的 `deepseek/deepseek-v4-pro`。
3. 在“API key 1”填入有 `typesafe/jev-1.14` 和对白模型访问权限的 OpenRouter key，点“保存配置”。两种模型可以共用一个 key。
4. 把“居民 AI”设为“开启”，选择天数，点“推进”。

也可以在本机仓库目录的 `.env.local` 中设置 `OPENROUTER_API_KEY`，再启动服务。多个 OpenRouter key 可以用 `OPENROUTER_API_KEYS` 配置，以逗号分隔。页面填写的 key 只保存在本地服务进程内存中，关闭服务或点击“清除页面 key”会移除它们。

本机版的对白平台也支持 OpenAI 和兼容接口。如果单独配置对白服务，仍需给 Jev 准备 OpenRouter key。本机页面默认连接 `http://127.0.0.1:8787`。环境变量中的 key 始终发往其平台的预设地址。缺少决定的活动可以由本地规则安排。

## 枫溪镇里有什么

- 小镇地图：看看今天镇上有哪些地方正在发生事情。
- 镇上居民：看看居民现在在哪里、今天打算做什么。
- 桌面舞台：地图是主要观察界面，30 位居民会在清晨、午后、夜里和归家四幕之间沿路线行走；移动时会迈步、起伏并朝向行进方向，到达后再切回浇水、维修、采购等行动。
- 今日小事：一天推进之后，镇上会留下新的动静。
- 镇上对话：可以在地图上看到居民交谈，或打开面板重读。开启居民 AI 时，对白来自当天实际碰面的两个人。
- 公告板：可以看到设施、账务、招标和公开消息。
- 周报时间线：时间走远一点之后，可以回看阶段记录。
- 六十天阶段回顾：每完成 60 天会出现一次小镇阶段评价、关系亮点和已审核模型对话回顾，关闭后仍可从周报时间线重新打开。

## 版本记录

2026-11-25，v0.3.0 接入 Jev 日程和互动决策，DeepSeek 为结算后的相遇写对白。GitHub Pages 的访客可直接阅读第一天的行程，也可以使用自己的 OpenRouter 账户推进新的日程。

维护在线版时，修改模型逻辑后运行 `sh town/scripts/build-browser-model.sh` 更新随网页发布的浏览器模块。Node 服务与浏览器使用同一套选择、写作和审核代码。

截至 2026-07-16，枫溪镇已更新至 v0.2.2，可以在浏览器中完整运行。30 位居民会在地图上行走、工作、来往和交谈；小镇已经包含日常经营、关系变化、四季节日、每日小报、周报和 60 天阶段回顾。不开启模型也能正常推进，开启后则会在本地事实和审核规则范围内丰富居民行动与对话。

v0.2.2 校正了居民步行路线和速度：每次移动都会保留审核路线上的全部转弯节点，不再用少量采样点穿过建筑或空地；移动时长按实际路程计算，短途至少 2.8 秒，长途会在下一幕开始前完成。原有的迈步、起伏、朝向和抵达动作继续保留，减少动态效果的系统设置仍会关闭这套动画。模型依然不能直接修改日期、路线、库存、账务或关系数值。

## 本地对白分层

关闭居民 AI 时，普通招呼以现场碎语留在地图上；当天行动或前一日记录支撑的两三句交流在居民附近依次出现；只有带明确关系事件证据的重要交流进入完整对话区。地图上的对话框以参与居民的实时中点为锚，居民沿路线行走时会保留原有避让距离并同步移动。居民在话里使用英文名的 first name，对白正文保持中文。

本地检查同时限制同日原句复用、相邻日同一话题骨架复用，以及无证据的“昨天”和重要对话。这套逻辑已经通过自动检查和 1280×720 桌面浏览器验收。
